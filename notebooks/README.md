# Kalanos notebooks

Open any notebook in Google Colab and choose **Runtime → Run all**. (The assignment notebook opens with its charts already saved; it only audits when you choose a fresh mode and tick **RUN_FRESH_AUDIT**.) Each runs on a CPU runtime, needs no Hugging Face token or Kalanos API key, and publishes nothing. For private or restricted data, use an approved local Jupyter environment instead.

- Kalanos, the helper packages and every dataset revision are pinned, so each run sees the same files. The Quickstart installs 0.10.0; the others install 0.10.1.
- The [published Hub reports](https://hub.kalanos.ai) are separate runs, so their counts can differ between grader releases.
- An audit describes the checks that ran. A pass does not establish task success or predict training results.
